# Nimi Preview Backlog

> 更新于 2026-11-24。macOS、Windows、Linux 均已进入 Preview，公开 API 仍可能调整。

## 当前优先级

1. **验收与 CI**。复核 macOS DMG 校验失败，检查并记录三平台实际桌面验收结果。
2. **IPC 与生命周期**。验证慢请求、流式数据、背压、取消、导航和关闭后的回调交付。
3. **桌面能力与示例**。跟进通知交互、拖放、媒体键和音乐缓存，按平台约束安排实现。
4. **发布**。验证签名、公证、安装和首次启动，再推进各平台的升级、回滚与分发。

各阶段通过条件见 [实施路线图](../05-roadmap.md#当前执行计划)。实现矩阵与自动化运行记录见 [开发基线](../28-remediation-status.md)。
