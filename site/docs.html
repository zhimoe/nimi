安装

使用源码构建 Nimi。安装 Nim 2.4+ 和对应平台的 C 工具链。

  • macOS 需要 macOS 12+ 和 Xcode Command Line Tools。
  • Windows 使用 GCC/MinGW。网页窗口需要 WebView2 Runtime。
  • Linux 需要 GTK3 和桌面会话。网页窗口需要 WebKitGTK 4.1，后端也支持 4.0。

Ubuntu 24.04 运行依赖

sudo apt install libgtk-3-0t64 libwebkit2gtk-4.1-0 libnotify4 \
  gstreamer1.0-plugins-base gstreamer1.0-plugins-good

快速开始

hello 运行系统 WebView 和 IPC，counter-native 运行自绘原生 UI。

macOS / Linux

git clone https://github.com/zhimoe/nimi.git
cd nimi
nim c -o:nimi src/nimi/cli.nim
./nimi doctor
./nimi generate examples/hello
./nimi dev examples/hello

# 关闭窗口后，试用原生 UI 并构建发布产物
nim c -r --path:src examples/counter-native/main.nim
./nimi build examples/hello

Windows PowerShell

git clone https://github.com/zhimoe/nimi.git
cd nimi
nim c -o:nimi.exe src/nimi/cli.nim
.\nimi.exe doctor
.\nimi.exe generate examples/hello
.\nimi.exe dev examples/hello

nim c -r --path:src examples/counter-native/main.nim
.\nimi.exe build examples/hello

nimi dev 监听 .nim、.nims 和 nimi.json，变化后重建并重启。

构建产物

示例默认输出到 examples/hello/dist/<平台>-<架构>/。

  • macOS 生成 .app 和 DMG，支持签名与公证配置。
  • Windows 生成内嵌 manifest 的 exe，并复制匹配架构的 WebView2Loader.dll。
  • Linux 生成可执行程序和 .desktop。安装 dpkg-deb 时也生成 .deb。

WebView 与类型化 IPC

Nim 侧用 bindService 显式暴露方法。宏在编译期读取 proc 签名, 生成 JSON 参数解码、结果编码和 TypeScript 客户端。 

import nimi

type
  Greeter = ref object

proc greet(self: Greeter, name: string): string =
  "Hello, " & name & "!"

let greeter = Greeter()
bindService(greeter, greet)

页面通过注入的 bridge 调用:

const text = await window.nimi.call("Greeter.greet", "Nim");

Bridge 在文档开始时注入，IPC 请求携带窗口的 secret 与 token。 为应用自己的页面注册服务，耗时操作可用 bindBackgroundService。

运行 ./nimi generate my-app 会生成 frontend/nimi.ts 和运行时客户端。生成器识别基础标量，其他类型映射为 unknown。

原生 UI

不需要 HTML 时,用 uiView 描述每帧的 Node 树。 布局、测量、绘制、命中、焦点和键盘都走同一套实现。 

import nimi
import nimi/ui

type
  Counter = ref object
    n: int

proc view(s: Counter, c: Context) =
  column(c).fill().center().gap(16).children(c, proc() =
    text(c, $s.n).fontSize(56).bold()
    row(c).gap(8).children(c, proc() =
      button(c, "+", (proc() = inc s.n), key = "inc")
    )
  )

let counter = Counter()
let content = uiView(proc(c: Context) = view(counter, c))

app.whenReady(proc() =
  discard newWindow(WindowOptions(
    title: "Counter",
    width: 360,
    height: 260,
    content: content
  ))
)
app.run()

已实现 Text、Button、Checkbox、Switch、Slider、Progress、Image、TextInput 和 TextArea。 长列表可使用 virtualList，Tester 可在无窗口环境验证布局和交互。

平台与 Preview

core 只依赖 platform/contract。macOS、Windows、Linux Preview 后端复用同一 Backend / NativeWindow / SurfaceHandler 模型。

平台状态实现
macOSPreviewAppKit、WKWebView、CoreGraphics、CoreText、NSMenu、NSOpenPanel/NSSavePanel
WindowsPreviewWin32、WebView2、GDI、原生菜单/IME/托盘
LinuxPreviewGTK3、WebKitGTK、Cairo/Pango、X11/MPRIS/GStreamer

本地媒体播放与系统媒体控制覆盖 macOS 和 Linux。托盘、快捷键、文件监视和 IME 的行为因系统与桌面环境而异。

示例

Nimi Notes 是当前的端到端验收:WKWebView 页面负责编辑与预览, Nim 负责 JSON 存储、原生菜单和文件对话框,最后打包成 Nimi Notes.app 与 DMG。 

notes_dir=$(mktemp -d)
NIMI_NOTES_DIR="$notes_dir" NIMI_SMOKE=crud \
  nim c -r --path:src examples/notes/main.nim
# smoke crud: ok (1 -> 2)

./nimi build examples/notes
hdiutil verify examples/notes/dist/darwin-*/nimi-notes-0.1.0.dmg

其他可运行示例：

  • examples/hello · 三平台 WebView、IPC 与页面事件。
  • examples/counter-native — 原生布局、鼠标、方向键、Tab+Enter。
  • examples/widgets-native — Checkbox/Switch/Slider/Progress/Divider。
  • examples/form-native — 原生表单、菜单、文件/消息对话框。
  • examples/music · macOS/Linux 原生音乐播放器、虚拟列表和系统媒体控制。
  • examples/environment · Windows 原生 UI、注册表与 UAC。
