原生桌面应用。

Nimi 是 MyGo 的 Nim 重实现:系统 WebView + 类型化 IPC + 自绘原生 UI + 一套桌面 API。编译为原生代码,没有运行时 VM, 也没有 cgo。

开始使用 在 GitHub 查看 ↗
  • 编译为 C
  • ARC / atomicArc
  • WKWebView + AppKit
  • 类型化 JSON IPC
hello.nim 
import nimi

type
  Greeter = ref object

proc greet(self: Greeter, name: string): string =
  "Hello, " & name & "!"

let greeter = Greeter()
bindService(greeter, greet)

app.whenReady(proc() =
  discard newWindow(WindowOptions(
    title: "Hello Nimi",
    html: page
  ))
)
app.run()
页面侧 await window.nimi.call("Greeter.greet", "Nim")

Why Nim

为什么用 Nim 写桌面应用?

Nim 把现代语言的表达力、C 的执行模型和直接的 C/ObjC FFI 放在一起。 对桌面框架来说,这三点正好对应启动速度、内存行为和系统集成。

01

没有 VM,也没有 cgo

Nim 编译为 C,再交给系统编译器生成原生二进制。直接调用 ObjC runtime、 AppKit、CoreGraphics,不需要 cgo 桥接层。

02

确定性的内存模型

使用 --mm:atomicArc:引用计数 + 原子操作,避免 GC 停顿。 跨线程只传值,主线程队列负责 UI 调度。

03

小二进制,快启动

Nimi 应用没有 Chromium/Node 运行时。WebView 来自系统, 业务代码和框架一起编译成几 MB 的可执行文件。

04

宏生成类型化 IPC

bindService(instance, procs...) 在编译期生成 JSON 参数解码、 结果编码和 TypeScript 客户端,页面调用有类型可循。

05

系统 API 直接可达

NSMenu、NSOpenPanel、NSPasteboard、WKWebView、CoreText 都是普通 FFI 调用。 平台后端是独立的 native 模块,不要求写 Objective-C 胶水文件。

06

同一套平台契约

core 层只依赖 platform/contract。macOS 先落地, Windows(Win32/WebView2/D3D11)和 Linux(GTK3/WebKitGTK/GL)沿用同一模型。

Framework

两条 UI 路径,一套核心。

需要富文本、复杂布局时用系统 WebView;需要完全自绘、贴近系统观感时用原生 UI。 两者共享窗口、菜单、事件和打包。

WebView-first

系统 WebView,隔离的 Bridge

WKWebView 承载页面,Nim 通过注入的 bridge 处理 window.nimi.call。每个窗口有独立 secret/token, 页面只能调用显式绑定过的服务。

page → secret + token → JSON dispatch → Nim proc
Native UI

自绘,不依赖 HTML

Column/Row 布局、CoreText 换行、Checkbox/Slider/TextInput 等控件, 以及命中测试、焦点、Tab/Enter、离屏 PNG 和 Tester。

Desktop API

菜单、对话框、剪贴板

NSMenu 角色与快捷键、NSOpenPanel/NSSavePanel/NSAlert、 文本/HTML 剪贴板,以及 Finder 可启动的 .app。

Tooling

从模板到 DMG

nimi init / generate / dev / build / doctor。 开发时源码变更自动重启;构建时生成 Info.plist、icns、签名和 DMG。

Testing

无窗口也能测试 UI

Tester 复用同一套布局、绘制和命中逻辑,直接断言文本、 点击、键盘、焦点和控件状态;离屏渲染输出 PNG。

tester.click("add"); tester.typeText("Ada"); check tester.hasText("Ada")

Architecture

core 不依赖具体平台。

应用策略、窗口、IPC、菜单和 UI 场景在上;平台契约在中; AppKit/WebView 或未来的 Win32/GTK 在下。

应用代码 Nim

ui / scene / render / text Column · Row · widgets · CoreText
↓

↓

Linux · 规划 GTK3 · WebKitGTK · OpenGL

Quick start

几分钟内跑起来。

需要 Nim 2.4+、macOS 12+ 和 Xcode Command Line Tools。

查看完整文档 ↗
zsh 
$ nim c -o:nimi src/nimi/cli.nim
$ ./nimi init my-app
$ ./nimi dev my-app

# 原生 UI 示例:Markdown 笔记应用
$ nim c -r --path:src examples/notes/main.nim

# 打包 .app + DMG
$ ./nimi build examples/notes
